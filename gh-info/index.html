oriz Quiz

AI quiz + flashcards — turn notes or a topic into MCQs or spaced-repetition cards, score yourself, and export. This page describes the project; the live tool runs elsewhere.

Open the live app → Source on GitHub llms.txt

What it is

Paste a chapter, lecture notes, or type a topic. AI writes a multiple-choice quiz or a flashcard deck. Take the quiz for an instant score with explanations, or drill the cards with the SM-2 spaced-repetition algorithm. Then export your results.

Key features

  • MCQ quiz — 3–30 AI questions, 4 options each, one-line explanations, answer-lock reveal.
  • Flashcards — front/back cards reviewed with SM-2 (Again / Hard / Good / Easy).
  • Saved decks — persist in IndexedDB; reopening surfaces only due cards.
  • Score + streak — streak confetti at 3+, a big burst on a perfect score.
  • Export — quiz to TXT / JSON, deck to CSV (Anki / Quizlet friendly).
  • Model picker — auto-failover by default, or choose any g4f model.
  • Sample fallback — empty input runs a built-in sample topic in one click.

Tech

  • Client-only Astro static site with a React island for the app.
  • Keyless AI via @chirag127/oz-ai (g4f / gpt4free, multi-provider failover).
  • PWA-installable and offline-capable.
  • 100% in-browser — no upload, no signup, no account; free.
